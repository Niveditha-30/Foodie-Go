# 🍔 FoodieGo — Flutter Food Delivery App

FoodieGo is a food delivery mobile application built with **Flutter and Dart**. It presents a simple food-ordering experience with food discovery, search, favourites, cart management, and a profile section.

> **Presentation note:** The ready-to-install Android APK is included in this repository under `apk/FoodieGo.apk`. You can download and install the APK on a compatible Android phone without installing Flutter.

## ✨ Features

- **Home screen:** Browse food items and categories.
- **Food cards:** View dishes with images, prices, and ratings.
- **Search:** Find food items quickly.
- **Favourites:** Keep favourite dishes in one place.
- **Cart:** Review selected items before ordering.
- **Food details:** View more information about a selected dish.
- **Profile and navigation:** Move between the main sections of the app.
- **Light and dark appearance:** Material-based UI styling.

## 📲 Try the App

1. Open the `apk` folder in this repository.
2. Download `FoodieGo.apk` to an Android phone.
3. Open the downloaded file and allow installation from that source if Android asks.
4. Install and launch FoodieGo.

Only install APK files you trust. Android may display a warning for apps installed outside the Play Store.

## 💻 Source Code and Rebuilding

The main Dart source is in `lib/main.dart`. The repository includes Flutter configuration, but generated platform folders may not be present yet.

To rebuild the application from source, a developer needs to install the Flutter SDK, generate the platform files, fetch dependencies, and run or build the app. Flutter is **not required** merely to view this repository or download the included APK.

## 🎯 Project Objective

The objective of FoodieGo is to demonstrate a mobile food-ordering interface that organizes food discovery and common ordering actions in one application.
